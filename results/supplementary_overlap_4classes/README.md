# Four-class overlap sweep — supplementary analysis

Entirely synthetic one-variable data: four equal-prior triangular classes, 11 adjacent-pair overlap levels from 100% to 0%, 20 dataset replicates and 100 starts per K=2–6. Each class has 100 training and 2,000 independent test observations. There are 110,000 configurations and 330,000 finite index values.

At disjointness, DB/k-means and DB/hardened FCM recover K=4 in 20/20 datasets each; SDB recovers it in 0/20, choosing K=3 in 17 datasets and K=2 in three. The new figures use linear axes.

K=1 is undefined: selection frequencies at complete overlap are not correct-count recovery. All files in this directory are synthetic; no original fMRI or participant data are included.
